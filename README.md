# анти-ии квен академия математика егэ-2027

Бесплатный социальный офлайн-проект — тренажёр ЕГЭ-2027 по математике (базовый и профильный уровни) по официальной демоверсии, кодификатору и спецификации ФИПИ.

> 🌐 **Онлайн-версия:** [ancf-hue.github.io/anti-ai-qwen-academy-math-ege-2027](https://ancf-hue.github.io/anti-ai-qwen-academy-math-ege-2027/)

## 📌 О проекте

Тренажёр работает в любом браузере без установки, без интернета и без регистрации. Все ответы проверяются локально — ваши данные никуда не отправляются. Поддерживает переключение между двумя уровнями сложности.

### Что внутри

- **Два уровня:** базовый и профильный
- **Базовый уровень:** 21 задание с кратким ответом, 180 минут, 21 первичный балл
- **Профильный уровень:** 13 заданий с кратким ответом + 7 заданий с развёрнутым ответом, 235 минут, 33 первичных балла
- Встроенный таймер экзамена с пресетами (180 / 235 / 60 минут)
- Чек-лист подготовки и подробный план на 25 дней
- Автопроверка для заданий с кратким ответом и честная самооценка по критериям ФИПИ для части 2

## 📚 Структура тренажёра

| Уровень | Задания | Первичные баллы | Время |
|---|---|---|---|
| **Базовый** | 21 (все с кратким ответом) | 21 | 180 мин |
| **Профильный** | 13 (краткий) + 7 (развёрнутый) | 33 | 235 мин |
